# Mã nguồn frontend

## Mục đích

Chứa toàn bộ mã nguồn ứng dụng SAW.

## Chứa gì?

`main.tsx` khởi chạy ứng dụng; `App.tsx` ghép các route.

## Ví dụ

`pages/` chứa màn hình; `components/` chứa giao diện dùng chung.

## Không nên đặt ở đây

Cấu hình Vite, package.json hoặc file môi trường; các file này ở root.
