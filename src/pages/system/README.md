# Màn hình hệ thống

## Mục đích

Chứa các màn hình thông báo chung của hệ thống.

## Chứa gì?

ForbiddenPage cho lỗi quyền truy cập và NotFoundPage cho đường dẫn không tồn tại.

## Ví dụ

`/403` hiển thị thông báo từ chối truy cập; `*` hiển thị trang không tìm thấy.

## Không nên đặt ở đây

Màn hình nghiệp vụ của từng vai trò hoặc code gọi API.
