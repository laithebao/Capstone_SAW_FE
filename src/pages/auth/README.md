# Màn hình xác thực

## Mục đích

Chứa các màn hình liên quan đến tài khoản và đăng nhập.

## Chứa gì?

Hiện chỉ có LoginPage dạng placeholder.

## Ví dụ

LoginPage; chỉ thêm ForgotPasswordPage hoặc RegisterPage khi đến phạm vi được giao.

## Không nên đặt ở đây

AuthContext, route guard hoặc code gọi API trực tiếp.
