# Màn hình Administrator

## Mục đích

Chứa các màn hình dành cho quản trị viên.

## Chứa gì?

Hiện chỉ có AdminDashboardPage dạng placeholder.

## Ví dụ

Sau này: UserAuthorizationPage, CropTypeManagementPage, InspectionStandardPage, AuditLogPage.

## Không nên đặt ở đây

Màn hình của vai trò khác hoặc component dùng chung.
