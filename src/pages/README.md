# Các màn hình

## Mục đích

Chứa màn hình hoàn chỉnh, chủ yếu được chia theo vai trò.

## Chứa gì?

Mỗi Page thường tương ứng một route hoặc một màn hình trong SRS Screen Flow.

## Ví dụ

Page có thể dùng component, hook, service và state riêng của màn hình.

## Không nên đặt ở đây

Component dùng lại giữa nhiều vai trò; chuyển chúng sang `components/`.
