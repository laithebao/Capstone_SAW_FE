# Thành phần khung giao diện

## Mục đích

Chứa component tạo nên khung giao diện chung.

## Chứa gì?

`Header.tsx` và `Sidebar.tsx` ở mức khung ban đầu.

## Ví dụ

DashboardLayout dùng chung Header và Sidebar cho sáu vai trò.

## Không nên đặt ở đây

Trang nghiệp vụ hoặc sáu bản Sidebar trùng lặp theo vai trò.
