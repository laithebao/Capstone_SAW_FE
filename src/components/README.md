# Component dùng chung

## Mục đích

Chứa các phần giao diện có thể dùng lại trên nhiều màn hình.

## Chứa gì?

`common/` cho UI chung; `layout/` cho thành phần khung ứng dụng.

## Ví dụ

Header và Sidebar được dùng trong DashboardLayout.

## Không nên đặt ở đây

Một trang nghiệp vụ hoàn chỉnh hoặc cấu hình route.
