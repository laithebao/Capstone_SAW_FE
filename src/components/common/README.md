# UI dùng lại

## Mục đích

Chứa component UI nhỏ được nhiều màn hình sử dụng.

## Chứa gì?

Chỉ thêm component khi có nhu cầu dùng thực tế.

## Ví dụ

Sau này có thể thêm Button, Input, Modal, Table, Pagination, StatusBadge.

## Không nên đặt ở đây

Page hoàn chỉnh, lệnh gọi API hoặc cấu hình route.
