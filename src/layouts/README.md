# Bố cục trang

## Mục đích

Chứa bố cục bao quanh các page.

## Chứa gì?

AuthLayout cho đăng nhập; DashboardLayout cho trang đã xác thực; PublicLayout cho trang công khai.

## Ví dụ

Dùng `Outlet` để hiển thị page con; DashboardLayout ghép Header và Sidebar.

## Không nên đặt ở đây

Logic nghiệp vụ, API hoặc thiết kế Stitch hoàn chỉnh ở giai đoạn này.
